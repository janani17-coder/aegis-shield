# Lab Rules

## Purpose
These rules keep the security practice lab private, safe, and legal.

## Rules
1. Test only applications I own or targets explicitly authorized for this lab. Testing other people's systems without permission can violate the law because it may involve unauthorized access or interference.
2. Keep the lab on my own computer and bind its ports to `127.0.0.1`. Never expose vulnerable applications to the internet or a shared network.
3. Use fictional data only. Never enter real personal or confidential information.
4. Record each finding with what happened, where it happened, how to reproduce it, its impact, and how to fix it.
5. If a tool asks to scan the whole network, decline and stop.
6. Use security tools only against the lab applications or other explicitly authorized targets.
7. Stop the lab when testing is finished and keep Docker configuration changes under review.

## Lab Targets
- OWASP Juice Shop: `http://127.0.0.1:3000`
- DVWA: `http://127.0.0.1:8081`

## Review
Review these rules before each lab session.

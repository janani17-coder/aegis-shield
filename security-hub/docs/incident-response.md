
# Incident Response

## Overview

Aegis Shield includes three incident response playbooks prepared for cybersecurity learning and tabletop exercises.

## 1. Payroll Data Breach

**Objective:** Provide a structured response to suspected unauthorised payroll data access or disclosure.

Response priorities:
- Validate the alert and identify the affected records.
- Preserve relevant audit evidence.
- Escalate to the appropriate security and payroll owners.
- Follow authorised containment and recovery procedures.
- Review access controls and export approvals.

## 2. Ransomware Incident

**Objective:** Document an organisational response approach for a suspected ransomware incident.

Response priorities:
- Escalate the incident to the security response team.
- Follow approved isolation and business continuity procedures.
- Preserve relevant evidence.
- Assess recovery readiness.
- Review backup and security controls.

## 3. Insider Salary Disclosure

**Objective:** Address suspected inappropriate access to or disclosure of salary information.

Response priorities:
- Review relevant access and audit records.
- Preserve evidence and document findings.
- Escalate through the approved organisational process.
- Review authorisation and data protection controls.
- Record corrective actions.
